## 機能

### 携帯電話の状態

- **ネットワーク状態**：SSID、IP アドレス、信号強度、接続速度
- **SIM カード状態**：キャリア名、SIM カード状態
- **バッテリー状態**：バッテリー残量、温度、充電状態、電源接続タイプ

### SMS 管理

- **受信箱/送信箱**：type フィールドで分類切替、独立ページネーション、分類カウント表示
- **SMS 送信**：手動入力または連絡先リストから選択
- **クイック返信**：リスト項目の「返信」エントリ、ワンクリックで送信フォームにジャンプし番号を事前入力
- **ページネーション**：履歴 SMS のページ送り

### 通話履歴

- **分類タグ**：着信、発信、不在着
- **不明番号**：電話番号を直接表示（プレースホルダー文ではなく）
- **並び順**：新しい順に並べ替え

### アクセスパスワード保護

- `mobix pwd` コマンドでアクセスパスワードを設定
- パスワードは AES-256-GCM で暗号化して設定ファイルに保存
- 未設定時はパスワード不要
- 設定/クリア後は再起動が必要

## 要件

本プロジェクトは Android デバイス上で実行する必要があり、Termux、Termux:API、Node.js に依存します。

### インストールが必要なアプリ

F-Droid 経由で以下のアプリをインストールすることを推奨します：

- [Termux](https://f-droid.org/en/packages/com.termux/)
- [Termux:API](https://f-droid.org/en/packages/com.termux.api/)

Termux と Termux:API は同じチャンネルからインストールすることを推奨します。署名やバージョンの不一致によりプラグインが正常に動作しない場合があります。

### Android 権限

プロジェクトは Termux:API 経由で Android のシステム機能を呼び出します。関連機能を初めて使用する際、システム設定で Termux:API に対応する権限を付与する必要があります。

通常は以下の場所で設定できます：

```
設定 → アプリ → Termux:API → 権限
```

Android のバージョンやスマートフォンのメーカーによりメニュー名が多少異なる場合があります。

コマンドと権限の対応関係：

| コマンド | 機能 | 必要な権限 |
| --- | ---| --- |
| termux-battery-status | バッテリー状態取得 | 通常追加権限不要 |
| termux-wifi-connectioninfo | Wi-Fi 接続情報取得 | ネットワーク権限；一部のシステムでは位置情報も必要 |
| termux-telephony-deviceinfo | デバイスと SIM カード情報取得 | 電話またはデバイス情報権限 |
| termux-sms-list | SMS 読取 | SMS 読取権限 |
| termux-sms-send | SMS 送信 | SMS 送信権限 |
| termux-contact-list | 連絡先読取 | 連絡先権限 |
| termux-call-log | 通話履歴読取 | 通話履歴権限 |

機能を使用しない場合、対応する権限は不要です。

### Android SMS 送信確認

一部の Android バージョンやスマートフォンシステムでは、初めて SMS を送信する際、手動確認を求めたり、SMS、有料 SMS などの認証プロンプトが表示される場合があります。

SMS 送信に失敗した場合、以下を確認してください：

Termux:API に SMS 権限が付与されていることを確認；
手動でテスト SMS コマンドを実行：

```bash
termux-sms-send -n "10086" ""
```

- システムが確認ウィンドウを表示した場合、手動で許可してください；
- システムが「有料 SMS」の許可を求めた場合、必要に応じて確認してください；
- システムが Termux または Termux:API のバックグラウンド実行を制限していないか確認してください；

一部のデバイスでは、特定のアプリをデフォルト SMS アプリに設定する必要がある場合があります。

<b>SMS 送信にはキャリアの通信料が発生する場合があります。まず自分の電話番号でテストすることを推奨します。</b>

### 温馨提示

Android システムがバックグラウンド実行を制限したり Termux プロセスを回収してサービスが中断するのを防ぐため、システム設定で以下を推奨します：

- Termux をバックグラウンド実行ホワイトリストに追加；
- Termux のバッテリー最適化または省電力制限を無効化；
- Termux のバックグラウンド実行を許可。

スマートフォンのブランドにより設定名が異なる場合があります。通常は以下の場所で関連オプションを見つけられます：

```text
設定 → アプリ → Termux → バッテリー
```

デバイスのシステムに応じて「バックグラウンド実行を許可」「制限なし」または類似のオプションを選択してください。

## Termux:API のインストール

Termux を開き、以下のコマンドを実行：

```bash
pkg update
pkg upgrade -y
pkg install termux-api -y
```

## インストール

### Node.js のインストール

- （推奨）Node.js LTS をインストール
   ```
   pkg install nodejs-lts -y
   ```
- 現在のバージョンをインストール
  ```
  pkg install nodejs -y
  ```

インストール完了後、以下のコマンドを実行してインストールの成功とバージョン番号を確認：

```bash
# Node.js のバージョン確認
node -v

# npm のバージョン確認
npm -v
```

### 方式 1：npm グローバルインストール（推奨）

```bash
npm install -g @hreign/mobix
```

インストール後、`mobix` コマンドがグローバルに使用可能になります。

### 方式 2：zip 配布

Node.js に関する知識と経験がある場合、
[Release](https://github.com/hreign/mobix-android/releases) から `mobix-app.zip` をダウンロードして解凍し実行：

```bash
node app/dist/server.js
```

## クイックスタート

```bash
# サービス開始（デフォルトポート 7788、バックグラウンド）
mobix start

# サービス状態確認
mobix status

# ブラウザでアクセス
# http://<デバイスIP>:7788

# サービス停止
mobix stop
```

## コマンド

### mobix start

Mobix サービスをバックグラウンドで開始します。ターミナルを閉じてもサービスは継続します。

```bash
mobix start                # デフォルトポート 7788
mobix start --port 8080    # ポート指定
```

### mobix stop

実行中のサービスを停止します。

```bash
mobix stop
```

### mobix status

サービス状態を表示します。PID とポート情報を表示します。

```bash
mobix status
```

### mobix restart

最新設定でサービスを再起動します。

```bash
mobix restart
```

### mobix pwd

アクセスパスワードを設定または表示します。パスワードは AES-256-GCM で暗号化されます。

```bash
mobix pwd                  # パスワード状態表示
mobix pwd mypassword       # パスワード設定
mobix pwd ""               # パスワードクリア
```

パスワード設定後は再起動が必要：

```bash
mobix pwd mypassword
mobix restart
```

### mobix port

リッスンポートを設定または表示します。

```bash
mobix port                 # 現在のポート表示
mobix port 9000            # ポート変更
```

ポート変更後は再起動が必要：

```bash
mobix port 9000
mobix restart
```

### mobix help

ヘルプ情報を表示します。

```bash
mobix help                 # トップレベルヘルプ
mobix help start           # start コマンドの詳細ヘルプ
```

## 設定

設定ファイルは `~/.mobix/config.json`、ファイル権限 0600。

```json
{
  "version": 1,
  "port": 7788,
  "password": {
    "algorithm": "aes-256-gcm",
    "iv": "...",
    "data": "..."
  }
}
```

| 設定項目 | 説明 | デフォルト |
|--------|------|--------|
| port | リッスンポート | 7788 |
| password | アクセスパスワード（暗号化） | なし（パスワード不要） |

ポート解決優先順位：設定ファイル > 環境変数 `PORT` > デフォルト 7788

パスワード解決優先順位：設定ファイル > 環境変数 `MOBIX_PASSWORD` > なし

## バックグラウンド実行

- `mobix start` はバックグラウンドデーモンとして起動、ターミナルを閉じてもサービス継続
- systemd / init / launchd に依存しない
- Android Termux では `termux-wake-lock` でデバイススリープによるサービス中断を防止可能
- PID ファイルは `~/.mobix/mobix.pid`、stop / status / restart コマンドで使用

## 国際化

現在アプリは 8 言語をサポート：中国語、英語、日本語、韓国語、フランス語、ドイツ語、スペイン語、ロシア語。

システム言語に基づいて自動切替、追加設定不要。

検出失敗またはサポートされていない言語が検出された場合、英語にフォールバック。
