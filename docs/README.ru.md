## Функции

### Состояние Телефона

- **Состояние сети**: SSID, IP-адрес, сила сигнала, скорость соединения
- **Состояние SIM-карты**: Название оператора, состояние SIM-карты
- **Состояние батареи**: Процент заряда, температура, состояние зарядки, тип источника питания

### Управление SMS

- **Входящие/Отправленные**: Переключение по полю type, независимая пагинация, счётчики по категориям
- **Отправка SMS**: Ручной ввод номера или выбор из контактов
- **Быстрый ответ**: Кнопка «Ответить» в элементах списка, переход одним кликом к форме отправки с предзаполненным номером
- **Пагинация**: Навигация по истории SMS

### Журнал Вызовов

- **Теги классификации**: Входящие, Исходящие, Пропущенные
- **Неизвестные номера**: Показать номер телефона напрямую (не текст-заполнитель)
- **Сортировка**: Обратный хронологический порядок

### Защита Паролем

- Установка пароля доступа через команду `mobix pwd`
- Пароль шифруется AES-256-GCM в файле конфигурации
- Без пароля если не установлен
- Перезапуск после установки/очистки пароля

## Требования

Этот проект должен работать на Android-устройстве и зависит от Termux, Termux:API и Node.js.

### Приложения для установки

Рекомендуется устанавливать следующие приложения через F-Droid:

- [Termux](https://f-droid.org/en/packages/com.termux/)
- [Termux:API](https://f-droid.org/en/packages/com.termux.api/)

Termux и Termux:API следует устанавливать из одного канала, чтобы избежать проблем с плагином из-за несовпадения подписи или версии.

### Разрешения Android

Проект вызывает системные функции Android через Termux:API. При первом использовании соответствующих функций необходимо предоставить Termux:API соответствующие разрешения в настройках системы.

Обычно можно найти в:

```
Настройки → Приложения → Termux:API → Разрешения
```

Названия меню могут немного отличаться в зависимости от версии Android и производителя телефона.

Соответствие команд и разрешений:

| Команда | Функция | Требуемое разрешение |
| --- | ---| --- |
| termux-battery-status | Получить состояние батареи | Обычно без дополнительного разрешения |
| termux-wifi-connectioninfo | Получить информацию о Wi-Fi | Разрешение сети; некоторые системы также требуют местоположение |
| termux-telephony-deviceinfo | Получить информацию об устройстве и SIM-карте | Разрешение телефона или информации об устройстве |
| termux-sms-list | Чтение SMS | Разрешение чтения SMS |
| termux-sms-send | Отправка SMS | Разрешение отправки SMS |
| termux-contact-list | Чтение контактов | Разрешение контактов |
| termux-call-log | Чтение журнала вызовов | Разрешение журнала вызовов |

Если функция не используется, соответствующее разрешение не требуется.

### Подтверждение отправки SMS в Android

Некоторые версии Android или системы телефона могут требовать ручного подтверждения при первой отправке SMS или показывать запросы авторизации для SMS, платных SMS и т.д.

Если отправка SMS не удаётся, проверьте следующее:

Подтвердите, что Termux:API предоставлено разрешение SMS;
Выполните вручную тестовую команду SMS:

```bash
termux-sms-send -n "10086" ""
```

- Если система показывает окно подтверждения, разрешите вручную;
- Если система просит разрешить «платные SMS», подтвердите при необходимости;
- Проверьте, не ограничивает ли система работу Termux или Termux:API в фоновом режиме;

Некоторые устройства могут требовать установить приложение как приложение SMS по умолчанию.

<b>Отправка SMS может повлечь расходы оператора. Рекомендуется сначала протестировать со своим номером телефона.</b>

### Советы

Чтобы избежать ограничения фоновой работы или перехвата процесса Termux системой Android, что приводит к прерыванию сервиса, рекомендуется в настройках системы:

- Добавить Termux в белый список фоновой работы;
- Отключить оптимизацию батареи или ограничения энергосбережения для Termux;
- Разрешить Termux работу в фоновом режиме.

Названия настроек могут отличаться в зависимости от бренда. Обычно можно найти в:

```text
Настройки → Приложения → Termux → Батарея
```

Выберите в зависимости от системы устройства «Разрешить фоновую работу», «Без ограничений» или подобный пункт.

Откройте Termux и выполните следующие команды:

```bash
pkg install termux-api -y
```

## Установка

### Установка Node.js

- (Рекомендуется) Установить LTS-версию Node.js
   ```
   pkg install nodejs-lts -y
   ```
- Установить текущую версию
  ```
  pkg install nodejs -y
  ```

После установки выполните следующие команды для проверки:

```bash
# Проверить версию Node.js
node -v

# Проверить версию npm
npm -v
```

### Способ 1: глобальная установка npm (рекомендуется)

```bash
npm install -g @hreign/mobix
```

Команда `mobix` будет доступна глобально.

### Способ 2: zip-дистрибуция

Если у вас есть знания и опыт работы с Node.js,
скачайте `mobix-app.zip` из [Release](https://github.com/hreign/mobix-android/releases), распакуйте и запустите:

```bash
node app/dist/server.js
```

## Быстрый Старт

```bash
# Запустить сервис (порт по умолчанию 7788, фоновый режим)
mobix start

# Проверить статус сервиса
mobix status

# Доступ через браузер
# http://<ip-устройства>:7788

# Остановить сервис
mobix stop
```

## Команды

### mobix start

Запустить сервис Mobix в фоновом режиме, переживает закрытие терминала.

```bash
mobix start                # Порт по умолчанию 7788
mobix start --port 8080    # Указать порт
```

### mobix stop

Остановить запущенный сервис.

```bash
mobix stop
```

### mobix status

Показать статус сервиса, PID и порт.

```bash
mobix status
```

### mobix restart

Перезапустить сервис с последней конфигурацией.

```bash
mobix restart
```

### mobix pwd

Установить или показать пароль доступа. Шифруется AES-256-GCM.

```bash
mobix pwd                  # Показать статус пароля
mobix pwd mypassword       # Установить пароль
mobix pwd ""               # Очистить пароль
```

Перезапуск после установки:

```bash
mobix pwd mypassword
mobix restart
```

### mobix port

Установить или показать порт прослушивания.

```bash
mobix port                 # Показать текущий порт
mobix port 9000            # Изменить порт
```

Перезапуск после изменения:

```bash
mobix port 9000
mobix restart
```

### mobix help

Показать справку.

```bash
mobix help                 # Общая справка
mobix help start           # Подробная справка для start
```

## Конфигурация

Файл конфигурации: `~/.mobix/config.json`, права 0600.

```json
{
  "version": 1,
  "port": 7788,
  "password": {
    "algorithm": "aes-256-gcm",
    "iv": "...",
    "data": "..."
  }
}
```

| Параметр | Описание | По умолчанию |
|--------|------|--------|
| port | Порт прослушивания | 7788 |
| password | Пароль доступа (зашифрован) | Нет (без пароля) |

Приоритет порта: файл конфигурации > env `PORT` > по умолчанию 7788

Приоритет пароля: файл конфигурации > env `MOBIX_PASSWORD` > нет

## Фоновый Сервис

- `mobix start` запускает фоновый демон, переживает закрытие терминала
- Не зависит от systemd / init / launchd
- В Android Termux: `termux-wake-lock` для предотвращения сна устройства
- PID-файл: `~/.mobix/mobix.pid`, используется stop / status / restart

## Интернационализация

Приложение поддерживает 8 языков: Китайский, Английский, Японский, Корейский, Французский, Немецкий, Испанский, Русский.

Автоматическое переключение по языку системы, без дополнительной настройки.

Если обнаружение не удалось или встречается неподдерживаемый язык, откат к английскому.
